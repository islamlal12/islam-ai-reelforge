# حزمة الموشن `motion-kit.js` — مستوى الشوريلز داخل هويتك (v3.6)

**ليش:** بعد مشهد إثبات أرقام ريل «نقول وداعاً لتعديل الفيديو؟» (27 سبتمبر 2026) قال المستخدم: «ايوااا كده من زمان… نبي الحركة الديناميكية هذي سواء لما أتكلم وأصير نص الشاشة، أو كرت صغير تحت، أو لما أختفي… ابي إبداع ماله حدود».
الحزمة = مكوّنات جاهزة بجودة عالية تركب على **نفس المحرّك ونفس الأوضاع** (R_DOWN · R_LOWER · R_OFF) — مو محرّك مواز.

## التحميل
```bash
cp scripts/motion-kit.js <work>/
```
وبـ`compose.html` تحت سكربت المحرّك وقبل سكربت مشاهدك: `<script src="motion-kit.js"></script>`

## الصناديق حسب الوضع
| الوضع | الصندوق `box` | ملاحظة |
|---|---|---|
| `R_DOWN` (أنت بالنص) | داخل `panelIn(t,s,e,()=>…)`: `{x:130,y:278,w:820,h:180}` | يتكبّر 1.2 وحده — مكوّن واحد بسيط (كاينتك، ختم، خانة تعليق، عدّاد صغير) |
| `R_LOWER` (كرت صغير تحت) | `{x:60,y:170,w:960,h:1150}` | المساحة الكبيرة: شبكة بطاقات، تايملاين، مقارنة أعمدة |
| `R_OFF` (بدونك) | `{x:60,y:170,w:960,h:1400}` | الشاشة كلها: `techFrame` + عدّاد ضخم + منحنى + بطاقات |
| `R_FULL` (ملء الشاشة) | فوق الفيديو مباشرة | `stamp` أو `kinetic` قصير بس — لا تغطي الوجه |

| `MK.timeline(t,o)` | تايملاين مونتاج + ماسات + رأس تشغيل + زر «رندر» | `steps:[…], clickAt` |

| `MK.promptBar(t,o)` | شريط أوامر الذكاء الاصطناعي (دارك بيل، تايب رايتر، زر إرسال، مؤشر) | `text, cps, delay, btnColor, box, bg, rtl, font` |

| `MK.repoCard(t,o)` | بطاقة GitHub داكنة بصعود 2% و12 فريم: Public، نجوم، forks | `repo, desc, stars, forks, language, langColor, box, dur` |
| `MK.wipeSlider(t,o)` | سلايدر مسح عمودي (Before/After) بـ30 فريم، مقبض دائري وكليبينغ | `dur, dir, drawBefore, drawAfter, beforeImg, afterImg, beforeLabel, afterLabel, box` |
| `MK.stamp(t,o)` | ختم مزدوج ينطبع مايل + موجة | `text, cx, cy, rot` |
| `MK.iconArray(t,o)` | شبكة أيقونات بشر «X من كل N» تتعبّى والمظلّلين يتلوّنون | `total, hot, cols, hotAt, pick` |

كل مكوّن: `o.s` بداية (اربطها بالكلمة: `wordsOf(i)[j].s`)، و`o.e` نهاية اختيارية (تلاشي 0.25ث).

## 🛠️ دوال دليل Chandler الأربعة الجديدة بالتفصيل (v3.7)

مجموعة مكوّنات مبنية بدقة هندسية ورياضية كاملة مستوحاة من تقنيات **Chandler Intelligence** ومصممة للتوافق الفوري مع هوية إسلام آي ونظام المشاهد (`R_DOWN` · `R_LOWER` · `R_OFF`).

### 1. `MK.promptBar(t, o)` — شريط أوامر الذكاء الاصطناعي (AI Prompt Bar)
يرسم كبسولة مظلمة فاخرة (`#2B2B2B`) بزوايا دائرية كاملة في الثلث العلوي من الشاشة (22.5% من الارتفاع و92.6% من العرض)، يكتب البرومبت بتأثير الآلة الكاتبة بخط Typewriter مع مؤشر وامض، وزر إرسال مع سهم للأعلى بلون التمييز البرتقالي ينبض بحيوية عند اكتمال النص.

* **البارامترات الكاملة:**
  - `t` *(Number)*: الزمن الحالي بالثواني.
  - `o.s` *(Number)*: زمن الدخول بالثواني (اربطه بـ `w[0].s`).
  - `o.e` *(Number, اختياري)*: زمن التلاشي والخروج.
  - `o.text` *(String)*: نص الأمر البرمجي أو البرومبت.
  - `o.cps` *(Number)*: سرعة الطباعة بحرف/ثانية (الافتراضي: `20`).
  - `o.delay` *(Number)*: مهلة تأخير قبل بدء الكتابة (الافتراضي: `0.25` ثانية).
  - `o.btnColor` *(String)*: لون زر الإرسال الدائري (الافتراضي: `col('ACC')` البرتقالي `#F97316` / `#D97757`).
  - `o.bg` *(String)*: لون خلفية الشريط (الافتراضي: `#2B2B2B`).
  - `o.font` *(String)*: خط النص (الافتراضي: Monospace Typewriter Stack: Courier New / Menlo / Consolas).
  - `o.box` *(Object)*: أبعاد الموضع `{x, y, w, h}` (الافتراضي: `{x: 40, y: 382, w: 1000, h: 100}`).
  - `o.rtl` *(Boolean)*: تفعيل النمط العربي تلقائياً (الزر باليسار والنص يبدأ من اليمين).

* **مثال تطبيقي:**
```javascript
// داخل مشهد R_OFF أو R_LOWER
MK.promptBar(t, {
  s: w[0].s,
  e: w[0].s + 4.2,
  text: 'Build a video editing automation script with Claude and Remotion',
  cps: 24,
  btnColor: '#F97316'
});
```

### 2. `MK.toolLabel(t, o)` — ملصق الأداة المنزلق (Logo Slide & Name Emergence)
المؤثر الأيقوني في ريلز التقنية: يظهر شعار الأداة (110 بكسل بحواف دائرية وظل عميق) عند ارتفاع 61.5% من الإطار متمركزاً، ويتلاشى ويكبر خلال 12 فريم (0.4 ثانية Ease-Out Cubic). بعدها ينزلق الشعار لليسار بينما ينبثق اسم الأداة (خط عريض 92 بكسل) من خلفه متجهاً لليمين خلال 12 فريم إضافية، ليستقر الشعار والاسم معاً بتوازن وتمركز تام في وسط الشاشة.

* **البارامترات الكاملة:**
  - `t` *(Number)*: الزمن الحالي.
  - `o.s` *(Number)*: زمن بدء ظهور الشعار.
  - `o.e` *(Number, اختياري)*: زمن الخروج والتلاشي.
  - `o.name` *(String)*: اسم الأداة المراد إظهاره (مثل `'Remotion'`, `'Claude'`, `'Whisper'`).
  - `o.logo` *(String)*: حرف أو رمز أو إيموجي يُرسم داخل الشعار في حال عدم تمرير صورة (مثل `'R'`, `'⚡'`).
  - `o.logoImg` *(HTMLImageElement)*: كائن صورة حقيقي للشعار بدقة كاملة.
  - `o.logoBg` *(String)*: لون خلفية بطاقة الشعار (الافتراضي: `col('ACC')`).
  - `o.size` *(Number)*: حجم مربع الشعار بالبكسل (الافتراضي: `110`).
  - `o.cy` *(Number)*: الارتفاع الرأسي لمنتصف العنصر (الافتراضي: `1180` = 61.5% من 1920).
  - `o.gap` *(Number)*: الفراغ بين الشعار واسم الأداة (الافتراضي: `24`).
  - `o.dur1` *(Number)*: مدة ظهور الشعار (الافتراضي: `12 / 30` = `0.4` ثانية).
  - `o.dur2` *(Number)*: مدة انزلاق الشعار وخروج الاسم (الافتراضي: `12 / 30` = `0.4` ثانية).
  - `o.nameColor` *(String)*: لون خط الاسم (الافتراضي: `#FFFFFF`).
  - `o.rtl` *(Boolean)*: دعم النمط العربي (ينزلق الشعار لليمين والاسم يخرج لليسار).

* **مثال تطبيقي:**
```javascript
MK.toolLabel(t, {
  s: w[2].s,
  e: w[2].s + 3.0,
  name: 'Remotion',
  logo: 'R',
  logoBg: '#0B84FE',
  cy: 1180
});
```

### 3. `MK.repoCard(t, o)` — بطاقة مستودع GitHub الداكنة (GitHub Repo Card)
بطاقة مستودع برمجية تحاكي الثيم الداكن الرسمي لـ GitHub (`#0D1117`) بإطار رمادي أنيق (`#30363D`) تظهر في أعلى الإطار بعرض 85% (918 بكسل) مع صعود ناعم بنسبة 2% (38.4 بكسل) خلال 12 فريم (0.4 ثانية). تحتوي على اسم المستودع بلون الروابط الأزرق (`#58A6FF`)، بادج `Public` المفرغ، وصف المشروع، لغة البرمجة بنقطتها الملونة، عدد النجوم (مع رسمة النجمة الخماسية)، وتعداد الـ Forks (مع أيقونة التفريع).

* **البارامترات الكاملة:**
  - `t` *(Number)*: الزمن الحالي.
  - `o.s` *(Number)*: زمن بدء ظهور البطاقة.
  - `o.e` *(Number, اختياري)*: زمن التلاشي.
  - `o.repo` *(String)*: مسار المستودع (`'owner/repo'`).
  - `o.desc` *(String)*: الوصف النصي للمشروع البرمجي.
  - `o.stars` *(Number)*: عدد النجوم الإجمالي (يتم تنسيقه تلقائياً `21.5K` / `1.4M`).
  - `o.forks` *(Number)*: عدد التفرعات (Forks).
  - `o.language` *(String, اختياري)*: لغة البرمجة (مثل `'TypeScript'`, `'Python'`).
  - `o.langColor` *(String, اختياري)*: لون نقطة اللغة (مثل `#3178C6` للتايب سكريبت أو `#3572A5` للبايثون).
  - `o.box` *(Object)*: صندوق الموضع `{x, y, w, h}` (الافتراضي: `{x: 81, y: 190, w: 918, h: 220}`).
  - `o.dur` *(Number)*: مدة صعود وتلاشي البطاقة (الافتراضي: `12 / 30` = `0.4` ثانية).

* **مثال تطبيقي:**
```javascript
MK.repoCard(t, {
  s: w[1].s,
  e: w[1].s + 3.8,
  repo: 'remotion-dev/remotion',
  desc: 'Create videos programmatically with React & Motion Graphics',
  stars: 21850,
  forks: 1420,
  language: 'TypeScript',
  langColor: '#3178C6'
});
```

### 4. `MK.wipeSlider(t, o)` — سلايدر مسح المقارنة العمودي (Before/After Wipe Slider)
أداة المقارنة البصرية للمونتاج والتلوين السينمائي: ينفذ مسحاً عمودياً سلساً بين نسختين (قبل / بعد) خلال 30 فريم (1.0 ثانية كاملة بتسارع تكعيبي متناغم `eInOut`). يتضمن خطاً أبيض ناصعاً بظل ناعم، مقبضاً دائرياً بداخله سهمان متقابلان `◀ ▶`، مع كليبينغ دقيق للجهتين يمنع أي تسريب بصري، وشارات اختيارية ("قبل" و"بعد").

* **البارامترات الكاملة:**
  - `t` *(Number)*: الزمن الحالي.
  - `o.s` *(Number)*: زمن بدء حركة المسح.
  - `o.e` *(Number, اختياري)*: زمن انتهاء التأثير كاملاً.
  - `o.dur` *(Number)*: مدة حركة خط المسح (الافتراضي: `1.0` ثانية = 30 فريم).
  - `o.dir` *(String)*: اتجاه حركة المسح (`'rtl'` من اليمين لليسار كدليل Chandler، أو `'ltr'`).
  - `o.drawBefore` *(Function)*: دالة لرسم نسخة "قبل" على الكانفس: `drawBefore(X)`.
  - `o.drawAfter` *(Function)*: دالة لرسم نسخة "بعد" على الكانفس: `drawAfter(X)`.
  - `o.beforeImg` *(HTMLImageElement / Canvas)*: صورة أو كانفس جاهز لنسخة "قبل".
  - `o.afterImg` *(HTMLImageElement / Canvas)*: صورة أو كانفس جاهز لنسخة "بعد".
  - `o.beforeLabel` *(String, اختياري)*: نص شارة البداية (مثل `'قبل التعديل'` أو `'Original'`).
  - `o.afterLabel` *(String, اختياري)*: نص شارة النتيجة (مثل `'بعد التعديل'` أو `'Graded'`).
  - `o.box` *(Object)*: حدود المسح (الافتراضي: ملء الشاشة `{x: 0, y: 0, w: 1080, h: 1920}`).
  - `o.lineColor` *(String)*: لون الخط الفاصل (الافتراضي: `#FFFFFF`).
  - `o.lineWidth` *(Number)*: سمك الخط (الافتراضي: `3.5`).
  - `o.handleRadius` *(Number)*: نصف قطر المقبض الدائري (الافتراضي: `24`).

* **مثال تطبيقي:**
```javascript
MK.wipeSlider(t, {
  s: w[0].s,
  e: w[0].s + 3.5,
  dur: 1.0, // 30 فريم
  dir: 'rtl',
  beforeLabel: 'قبل التلوين',
  afterLabel: 'النتيجة',
  drawBefore: (X) => {
    // رسم الإطار الخام للفيديو قبل الفلاتر
    if (rawFrame) X.drawImage(rawFrame, 0, 0, 1080, 1920);
  },
  drawAfter: (X) => {
    // رسم الإطار بعد المعالجة وتعديل الألوان
    if (gradedFrame) X.drawImage(gradedFrame, 0, 0, 1080, 1920);
  }
});
```

## مثال — جملة «ريل واحد جاب قريب مليون مشاهدة» بوضع R_OFF
```html
<script src="motion-kit.js"></script>
<script>
SCENES=[{s:0,e:3.2,m:R_FULL},{s:3.2,e:8.6,m:R_OFF,nocap:true},{s:8.6,e:99,m:R_FULL}];
function viewsScene(t){ if(t<3.2||t>8.6) return; const w=wordsOf(1), hit=w[3].s;      // «مليون»
  MK.techFrame(t,{s:3.2,e:8.6,title:'إحصائيات ريل'});
  const [dx,dy]=MK.shake(t,hit+1.4); X.save(); X.translate(dx,dy);
  MK.odometer(t,{s:hit-0.5,dur:1.9,val:963007,cx:540,cy:640,size:170,e:8.6});
  MK.lineChart(t,{s:hit+1.2,dur:1.2,box:{x:110,y:780,w:860,h:420},max:'1M',e:8.6}); X.restore(); }
SCENE_LIST.push(['viewsScene',viewsScene]);
</script>
```
وبـ`sfx.json`: `"counter":[[البداية, 1.9]]` (تكات تتسارع وتتباعد مع العدّاد) + `"thud":[لحظة الخبطة]` + `"tap":[لحظات انبثاق البطاقات]`.

## ⛔ الحزمة أساس مو قالب (أمر المستخدم 27 سبتمبر)
«ما أبي تكون محدود بالحركات اللي أضفتها بحيث تكون متكررة… أنت عندك علم الموشن قرافيكس والإنفوقرافيك وتقرر شنو يحتاج المشهد».
المكوّنات فوق = مفردات جاهزة. **كل جملة تُصمَّم من معناها** — ابنِ فوق المكوّن، اكسره، أو ارسم شي جديد كلياً بالكانفس. ممنوع نفس المشهد بفيديوهين.

### جدول القرار: نوع المعلومة ← الشكل
| يقول | نوع المعلومة | الشكل الإنفوقرافيكي (أمثلة — مو حصر) |
|---|---|---|
| «4 من كل 100 يصابون» | جزء من كل | شبكة 100 أيقونة و4 تنور (`iconArray`) · 100 نقطة تتبعثر و4 تتجمع |
| «النص تقريباً» / 38% | نسبة | دونات تتعبّى · كوب يمتلي لين الخط · شريط ينشق |
| «زادت / نزلت» | اتجاه | منحنى يرتسم · سهم يطلع وينكسر · درج يصعد |
| «أكثر من / أقل» | مقارنة | عمودين · كفتين ميزان · دائرتين بحجمين |
| «الأول، الثاني…» | ترتيب | سباق أعمدة · منصة تتويج · قائمة تنقلب |
| «تصوّر ← ترفع ← تنشر» | عملية | خط زمن بخطوات · أسهم تتسلسل · تايملاين |
| «بـ3 ثواني / كل يوم» | زمن | ساعة تلف · عدّاد تنازلي · تقويم يتقلب |
| «بالكويت / الخليج» | مكان | خريطة مبسطة ودبوس ينزل · موجات من نقطة |
| «100 دينار / مليون» | مال | عملات تتكدس · فاتورة تنطبع · رقم يخبط |
| «لأن / فصار» | سبب ونتيجة | دومينو يطيح · ترس يلف ترس · سلسلة تنكسر |
| «خطأ / خلل» | مشكلة | قليتش + شقوق · علامة ✕ تخبط · شاشة تسوّد |
| اقتباس / جملة قوية | رسالة | كاينتك تايبو بالكشيدة · كلمة تتمدد · نص ورا الراس |

### لوحة الأصوات (`sfx.json`) — صوت لكل حدث بصري
| الحدث | المفتاح | الصيغة |
|---|---|---|
| عنصر يدخل / ينتقل | `whoosh_up` · `whoosh_down` · `soft` | `[ثانية]` · `[[ثانية, قوة]]` |
| عدّاد يركض | `counter` | `[[بداية, مدة]]` |
| خبطة رقم / لحظة كبيرة | `thud` + `sub` | `[ثانية]` |
| قبل كشف مهم | `riser` | `[[لحظة الكشف, مدة]]` (ينتهي عليها) |
| بطاقة / فقاعة تطلع | `pop` | `[ثانية]` |
| زر / اختيار / أيقونة تنور | `click` · `tap` | `[ثانية]` |
| نص ينكتب | `type` | `[[بداية, مدة]]` |
| تظليل كلمة / لمعة | `shimmer` | `[ثانية]` |
| خطأ / انكسار | `glitch` | `[ثانية]` |
**الصمت أداة:** شيل كل الأصوات نص ثانية قبل الجملة الأهم. ≤ 15 حدث بالدقيقة (التكات لحظة وحدة).

## قواعد الإبداع (لا تكسرها)
1. **الرسمة دليل على الكلمة مو زينة** — يقول رقم ← عدّاد يخبط على نفس الكلمة؛ يقول «زاد» ← منحنى؛ يقارن ← أعمدة؛ يعدّد ← بطاقات بتتابع؛ يطلب تعليق ← خانة تعليق. اعصف 3 أفكار لكل جملة واختر أقواها.
2. **بطل واحد بالمشهد** — مكوّن رئيسي واحد + مساند واحد على الأكثر بـ`R_DOWN`؛ `R_LOWER`/`R_OFF` يستحملون شبكة.
3. **الخبطة على الكلمة المنطوقة** — `dur` العدّاد ينتهي على `w.s` الكلمة (الرقم نفسه)، والرجّة والانفجار والصوت بنفس الفريم.
4. **أرقام حقيقية فقط** — من المستخدم أو من مصدر؛ لا تخترع رقم عشان تستعمل العدّاد.
5. **الهوية ثابتة** — ألوان `theme.json` (ACC/INK/BG/CLAY)، خط المحرّك، الشبكة؛ الحزمة تقرأها تلقائياً.
6. **المنطقة الآمنة وقاعدة الكابشن كما هي** — `R_OFF` بلوحة فيها النص → `nocap:true`؛ لا نص تحت y 1500 إلا الكابشن.
7. **الإيقاع** — كل مكوّن يثبت ≥ 1.2 ث بعد ما يكتمل؛ المؤثرات على اللحظات بس (≤ 15 بالدقيقة، التكات تنحسب لحظة وحدة).
8. **عاين قبل الرسم الكامل** — ورقة 6 لقطات (الخطوة 7) ولقطة وحدة عند كل خبطة.
