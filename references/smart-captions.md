# 🎯 دليل الكابشن الذكي والتايبوجرافي (Smart Captions & Typography Reference)

> **المعيار المعتمد من المستخدم:**
> "وعندما يتم كتابة الcaption أو subtitle في الفيديو، يجب أن لا يكون حجمه كبيراً ومزعجاً للمشاهد بل يكون متوسطاً إلى صغير الحجم ليكون سهل القراءة والمشاهدة. لذلك قم بتحديد الحجم بشكل ذكي جداً. ويجب أيضًا التأكد من صحة الـ caption وسلامته اللغوية ومطابقته بشكل كبير لصوت المتكلم، لعدم وجود أخطاء أو فرفشة للمشاهد."

---

## 1. فلسفة التصميم (Design Philosophy)

سابقاً كانت أحجام خطوط الكابشن ضخمة جداً (64px - 84px، وتصل في بعض الأنماط إلى 110px أو 170px)، مما يملأ منتصف الكادر ويغطي وجه المتحدث ويشتت انتباه المشاهد.
تمت إعادة معايرة نظام الكابشن بالكامل ليعتمد **المقياس المتوسط-المضغوط الذكي (Compact-to-Medium)** الذي يحقق:
1. **أقصى راحة بصرية:** حجم خط متوسط إلى مائل للصغر (42px - 50px).
2. **تركيز واحتفاظ فائق (High Retention):** دفعات سريعة من 1 إلى 3 كلمات فقط على الشاشة في اللحظة الواحدة.
3. **صفر فرفشة (Zero Jitter):** خط ارتكاز رأسي ثابت بدون أي قفزات أو اهتزازات رأسية.
4. **سلامة لغوية وتوافق لهجات صارم:** تصحيح أخطاء وِسبر الصوتية، والهمزات، والتاء المربوطة، والمصطلحات التقنية.

---

## 2. معادلة تحديد الحجم الذكي (Font Sizing Formula)

يتم احتساب حجم الخط وارتفاع السطر ديناميكياً وفق عدد كلمات الدفعة الواحدة المعروضة:

$$\text{Font Size} = \begin{cases} 
48\text{ px} & \text{إذا كان عدد الكلمات } \le 2 \\
44\text{ px} & \text{إذا كان عدد الكلمات } = 3 \\
42\text{ px} & \text{إذا كان عدد الكلمات } \ge 4 \text{ (حالة احتياطية)}
\end{cases}$$

- **النطاق الأساسي الصارم:** من 42px إلى 50px فقط.
- **ارتفاع السطر (Line Height):**
  $$\text{Line Height} = \text{round}(\text{Font Size} \times 1.30) \approx 55\text{px} - 63\text{px}$$
- **المسافة بين الكلمات (Inter-word Gap):** 14px لتفادي التداخل في الخطوط العربية.
- **الخط المعتمد:** `Readex Pro-Bold` (أو `Tajawal` أو `Cairo` كبدائل مدعومة).

## 3. إحداثيات المنطقة الآمنة (Safe Zone Coordinates)

في الفيديوهات الرأسية بدقة $1080 \times 1920$ (أبعاد 9:16)، توجد قيود صارمة تفرضها واجهات المنصات (إنستغرام وتيك توك):

```
       0 px ┌────────────────────────────────────────┐
            │   منطقة اسم الحساب والمتابعة (أعلى)    │
     150 px ├────────────────────────────────────────┤
            │                                        │
            │          منطقة الفيديو والوجه          │
            │                                        │
    1320 px ├────────────────────────────────────────┤ ◄─── بداية المنطقة الآمنة للكابشن
            │   ████ الكابشن الذكي (Y = 1370 px) ████ │
    1420 px ├────────────────────────────────────────┤ ◄─── نهاية المنطقة الآمنة للكابشن
    1500 px ├────────────────────────────────────────┤ ◄─── الحزام الحذر (ممنوع تجاوزه)
            │      أزرار الصوت، الكابشن، التفاعل     │
    1920 px └────────────────────────────────────────┘
```

- **الارتكاز الرأسي الافتراضي:** $Y_{\text{center}} = 1370\text{ px}$ (بين 1320px و 1420px، أي بنسبة 60% إلى 65% من ارتفاع الشاشة).
- **الحد الأقصى لأسفل الكابشن:** $\le 1460\text{ px}$ لعدم الاقتراب من كابشن إنستغرام أو اسم الصوت (يبدأ عند $1500\text{ px}$).
- **الحد الأفقي:** الكابشن متمركز أفقياً عند $X = 540\text{ px}$، بأقصى عرض $780\text{ px}$، تاركاً هامش أمان جانبي $150\text{ px}$ يميناً ويساراً لتجنب أعمدة التفاعل (أزرار المشاركة واللايك على الجانب الأيمن).
- **وضع الفيديو المرتفع والمنخفض:** في حال وجود كرت فيديو تحت (`R_DOWN` أو `R_LOWER`)، يرتفع الكابشن تلقائياً فوق كرت الفيديو ($Y = \_R.y - 42\text{ px}$) لضمان عدم كتابة أي كلمة فوق وجه المتحدث نهائياً.

## 4. تصميم تظليل الكلمة النشطة وصفر فرفشة (Active Word Styling & Zero Jitter)

### أ) صندوق الكلمة النشطة (Active Word Rounded Box):
- **نصف قطر الانحناء:** **8px** بالضبط (`border-radius: 8px` / `rr(..., 8)`).
- **حشوة الصندوق (Padding):** 10px أفقياً، 4px رأسياً.
- **لون التعبئة:** لون التمييز الأساسي للهوية:
  - أورانج إسلام آي: `#F97316`
  - كورال: `#D97757`
  - أو `theme.acc` المحدد في المشروع.
- **لون النص المنطوق:** `onAcc` المتوافق عالي التباين (أبيض `#FFFFFF` أو كحلي داكن حسب تباين الخلفية).

### ب) الكلمات غير النشطة (Inactive Words):
- تظهر باللون الأبيض الناصع `#FFFFFF`.
- ظل ناعم مريح للعين: `rgba(0, 0, 0, 0.70)` مع تنعيم `blur: 12px` وإزاحة رأسية `offsetY: 3px`.
- **منع الخلفية الكاملة للجملة:** يُمنع وضع شريط ملون كامل خلف الجملة؛ الصندوق المنحني يظهر فقط على الكلمة المنطوقة في لحظة نطقها.

### ج) القضاء التام على الفرفشة (Zero Jitter Elimination):
- إلغاء قفزة الارتفاع الرأسية القديمة (`lift = -6px`) التي كانت تجعل الكلمات تقفز لأعلى وأسفل كلما بدأت كلمة جديدة.
- تثبيت خط الأساس الرأسي (`textBaseline = 'middle'`) لكامل الدفعة.
- التلاشي الناعم عند بداية ونهاية الدفعة بدون أي اهتزاز في المقياس.

## 5. التدقيق اللغوي ومطابقة اللهجات (`02d_caption_linguistics.py`)

تعمل وحدة التدقيق اللغوي ومطابقة اللهجات آلياً قبل بناء الكابشن، وتغطي القواعد التالية:

### أ) تصحيح أخطاء وِسبر في اللهجات الدارجة:
- **المصرية:**
  - `ايه` / `اية` $\to$ `إيه`
  - `ايوه` / `أيوة` / `ايوة` $\to$ `أيوه`
  - `علشان` / `عاشان` $\to$ `عشان`
  - `كدة` / `كدا` $\to$ `كده`
  - `دة` / `دا` $\to$ `ده`
  - `دي` / `دى` $\to$ `دي`
  - `دلوقتى` $\to$ `دلوقتي`
  - `ازاي` $\to$ `إزاي`
- **الخليجية والشامية والمغاربية:**
  - `ايش` / `أيش` $\to$ `إيش`
  - `هادا` / `هاد` $\to$ `هذا`
  - `هسا` $\to$ `هسه`
  - `ياريت` $\to$ `يا ريت`
  - `ياجماعة` $\to$ `يا جماعة`
- **التعابير الشائعة:**
  - `ان شاء الله` / `انشاء الله` $\to$ `إن شاء الله`
  - `ماشاء الله` $\to$ `ما شاء الله`
  - `باذن الله` $\to$ `بإذن الله`
  - `واللهي` $\to$ `والله`

### ب) تصحيح وضبط الهمزات الشائعة:
- **همزة القطع المكسورة:** `الي` $\to$ `إلى`، `الا` $\to$ `إلا`، `اذا` $\to$ `إذا`، `ان` $\to$ `إن`، `انتاج` $\to$ `إنتاج`، `انترنت` $\to$ `إنترنت`، `انجاز` $\to$ `إنجاز`، `اعلان` $\to$ `إعلان`، `ادارة` $\to$ `إدارة`.
- **همزة القطع المفتوحة:** `اكبر` $\to$ `أكبر`، `افضل` $\to$ `أفضل`، `احسن` $\to$ `أحسن`، `اكثر` $\to$ `أكثر`، `اهم` $\to$ `أهم`، `اول` $\to$ `أول`، `اداة` $\to$ `أداة`، `اوامر` $\to$ `أوامر`، `ارقام` $\to$ `أرقام`، `اسماء` $\to$ `أسماء`، `ايام` $\to$ `أيام`.
- **المدّة والظرفية:** `اخر` $\to$ `آخر`، `الان` $\to$ `الآن`، `ايضا` $\to$ `أيضاً`.

### ج) التاء المربوطة (ة) مقابل الهاء (ه):
- تصحيح الكلمات التقنية والإعلامية التي يخلط وِسبر بين نهاياتها:
  - `تقنيه` $\to$ `تقنية`، `برمجه` $\to$ `برمجة`، `طريقه` $\to$ `طريقة`، `خطوه` $\to$ `خطوة`، `منصه` $\to$ `منصة`، `قناه` $\to$ `قناة`، `حلقه` $\to$ `حلقة`، `نتيجه` $\to$ `نتيجة`، `صوره` $\to$ `صورة`، `خدمه` $\to$ `خدمة`، `تجربه` $\to$ `تجربة`، `فرصه` $\to$ `فرصة`، `نسخه` $\to$ `نسخة`، `فائده` $\to$ `فائدة`.
- **حماية الكلمات المنتهية بهاء أصلية (True Haa Words):** منع لمس الكلمات الأصلية مثل:
  - `وجه`، `فقه`، `شبه`، `منبه`، `الله`، `إله`، `معه`، `له`، `به`، `عنه`، `منه`، `فيه`، `عليه`، `إليه`.

### د) توحيد مصطلحات الذكاء الاصطناعي وصناع المحتوى:
- `شات جى بى تى` / `شات جي بي تي` / `شاتجبتي` $\to$ `ChatGPT`
- `كلود` / `كلاود` $\to$ `Claude`
- `كورسور` $\to$ `Cursor`
- `ميدجورني` $\to$ `Midjourney`
- `جيميني` $\to$ `Gemini`
- `اي اي` / `أي آي` $\to$ `AI`
- `اي بي اي` $\to$ `API`
- `برومبت` / `برومت` $\to$ `برومبت`
- `ريل` / `ريلز` $\to$ `ريل` / `ريلز`
- `فديو` $\to$ `فيديو`
- `انستغرام` / `انستقرام` $\to$ `إنستغرام`
- `تكتوك` $\to$ `تيك توك`
- `يوتوب` $\to$ `يوتيوب`
- `لينكدإن` $\to$ `لينكد إن`
- `بودكاست` $\to$ `بودكاست`

### هـ) القواميس المخصصة (Custom Lexicon Override):
يدعم النظام تحميل قواميس إضافية خاصة بالمشروع من ملف `fixes.json`:
```json
{
  "dict": {
    "مفتاح": "قيمة مصححة",
    "برنامجنا": "تطبيق إسلام آي"
  }
}
```

### و) التحقق من سلامة التوقيتات وتفادي الوميض (Verbatim Audio Verification):
- **الترتيب الزمني الصارم:** $s < e$ لكل كلمة.
- **الحد الأدنى لظهور الكلمة:** $\ge 0.12\text{ s}$ لمنع وميض الكلمات السريع واختفائها في طرفة عين.
- **سلاسة الاتصال بين الكروت:** $card_i.e \le card_{i+1}.s - 0.02\text{ s}$ لمنع تراكم النصوص أو الاصطدام الزمني.

## 6. سير العمل البرمجي (Execution Pipeline)

```bash
# 1. التدقيق اللغوي وتوليد الكروت الذكية (42-50px):
python scripts/02_captions.py <workdir>

# 2. فحص المنطقة الآمنة تلقائياً:
node scripts/08_safe_check.js <workdir>

# 3. رسم الفريمات بجودة عالية بالخط واللون المعتمد:
node scripts/04_render_frames.js <workdir> all
```
