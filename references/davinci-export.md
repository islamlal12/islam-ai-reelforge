# 🎞️ تصدير التايم-لاين إلى دافينشي ريزولف (DaVinci Resolve Integration)

> **الإصدار:** 1.0.0 (متوافق مع DaVinci Resolve 17, 18, 19, 20)  
> **الصيغ المدعومة:** FCPXML v1.8/v1.9 · FCP7 XML (xmeml v5) · DaVinci Studio Python Scripting API · SRT · EDL/CSV Markers  
> **الأبعاد القياسية:** 1080×1920 (عمودي 9:16 ريلز وشورتس وتيك توك)

---

## 🎯 نظرة عامة والهدف

بدلاً من الاكتفاء بفيديو نهائي مصمت (MP4)، يتيح لك سكربت `scripts/42_davinci_export.py` تصدير مشروع وتايم-لاين كامل ومتعدد المسارات إلى برنامج المونتاج والتلوين الاحترافي **DaVinci Resolve**:

1. **مسار الفيديو الرئيسي (Track V1):** جميع مقاطع الكلام واللقطات مقصوصة بدقة الفريم بناءً على خوارزمية السكتات ومحو التلعثم (`cut.json`).
2. **مسار الصوت البشري (Track A1):** حوار المتحدث المنظف والمحسّن بنقاء الإذاعة (`a_clean.wav` أو `audio.wav`) متزامن فريم-بفريم مع لقطات الفيديو.
3. **مسار المؤثرات الصوتية (Track A2):** جميع ضربات الهيرو (Hero Hits)، والمؤثرات الصاعدة المقيّدة (Clamped Risers)، وأصوات الانتقال (Whooshes, Pops, Clicks) موضوعة في توقيتاتها الزمنية الدقيقة من `sfx.json`.
4. **مسار الترجمة والعلامات (Subtitle Track & Markers):** علامات زمنية ملوّنة (Timeline Markers) بكل كروت الكابشن والكلمات المشددة من `caps.json`، بالإضافة لملف ترجمة `.srt` للمسار المخصص.
5. **سكربت الاستيراد التلقائي بضغطة زر (`import_to_davinci.py`):** يتحكم في DaVinci Resolve Studio عبر Python API لإنشاء المشروع وضبط الدقة واستيراد التايم-لاين دون تدخل يدوي!

## 📦 حزمة الملفات المولّدة داخل المجلد

عند تشغيل السكربت على أي مجلد عمل (`workspace`):

```bash
python scripts/42_davinci_export.py <work_dir> [--fps 30] [--import]
```

تتولد الملفات التالية تلقائياً داخل `<work_dir>`:

| الملف | الوصف والاستخدام |
| :--- | :--- |
| `timeline.fcpxml` | **التايم-لاين الرئيسي:** بصيغة Final Cut Pro XML v1.8/v1.9 المتوافقة تماماً مع DaVinci Resolve 17-20. |
| `timeline.xml` | **التايم-لاين الرديف:** بصيغة Final Cut Pro 7 XML (xmeml v5) بمسارات منفصلة ومباشرة. |
| `import_to_davinci.py` | **أتمتة بايثون الذكية:** سكربت مستقل يتصل بـ DaVinci Resolve Studio ويبني المشروع فوراً. |
| `timeline.srt` | **ملف الترجمة الفورية:** جاهز للسحب والإفلات على مسار الترجمة (Subtitle Track). |
| `markers.csv` | **علامات دافينشي:** استيراد الكابشن كعلامات ملونة على مسطرة التايم-لاين عبر CSV. |
| `markers.edl` | **علامات بصيغة EDL:** استيراد العلامات بألوان دافينشي المعيارية ومددها الزمنية. |
| `sfx_clips/` | **مكتبة المؤثرات الصوتية:** ملفات WAV استريو 48kHz نقية لكل مؤثر صوتي في الفيديو. |

## 🚀 طرق الاستيراد في DaVinci Resolve

### الطريقة الأولى: الاستيراد التلقائي بضغطة زر (DaVinci Resolve Studio API)

إذا كان برنامج DaVinci Resolve Studio مفتوحاً على جهازك:

1. افتح موجه الأوامر أو الطرفية وشغّل السكربت إما عبر `--import`:
   ```bash
   python scripts/42_davinci_export.py "workspace" --import
   ```
   أو مباشرة بتشغيل سكربت الاستيراد من مجلد المشروع:
   ```bash
   python "workspace/import_to_davinci.py"
   ```
2. سيقوم السكربت بـ:
   - الاتصال بـ DaVinci Resolve فوراً عبر `DaVinciResolveScript`.
   - إنشاء مشروع جديد باسم الفيديو أو فتح المشروع الحالي.
   - ضبط أبعاد التايم-لاين على **1080×1920 (Vertical 9:16)** ومعدل الفريمات (30fps أو الأصلي).
   - استيراد كافة أصول الفيديو والصوت والمؤثرات إلى حوض الوسائط (Media Pool).
   - استيراد التايم-لاين `timeline.fcpxml` وتفعيله.
   - زرع علامات زمنية ملونة (Colored Duration Markers) لكل جملة وكابشن على المسطرة.
   - فتح صفحة المونتاج (Edit Page) تلقائياً لتكون جاهزاً للعمل!

---

### الطريقة الثانية: الاستيراد اليدوي المباشر عبر الواجهة (GUI)

تعمل هذه الطريقة على **جميع نسخ دافينشي ريزولف (المجانية والمدفوعة Studio)**:

1. افتح DaVinci Resolve وأنشئ مشروعاً جديداً.
2. من القائمة العلوية:
   `File` > `Import` > `Timeline...` > `Import AAF, EDL, XML...` (أو اضغط `Ctrl+Shift+I` في ويندوز / `Cmd+Shift+I` في ماك).
3. اختر ملف `timeline.fcpxml` (أو `timeline.xml`) من مجلد العمل.
4. في نافذة إعدادات الاستيراد:
   - تأكد من تفعيل: **Use timeline resolution** -> واختر **1080x1920**.
   - تأكد من تحديد مجلد العمل للبحث التلقائي عن الوسائط (Automatically link media).
5. اضغط **OK** — سيظهر التايم-لاين فوراً بجميع المقاطع المقصوصة والصوت والمؤثرات الصوتية!

---

### الطريقة الثالثة: إضافة الترجمة والعلامات (Subtitles & Markers)

1. **إضافة مسار الترجمة (Subtitle Track):**
   - في صفحة المونتاج (Edit Page)، انقر بالزر الأيمن على رأس المسارات في التايم-لاين واشترط `Add Subtitle Track`.
   - اسحب ملف `timeline.srt` وأفلته في مسار الترجمة ليتحول إلى كتل نصوص أصلية مدمجة بالكامل!
2. **استيراد العلامات الملونة (Markers):**
   - في صفحة المونتاج أو شريط الوسائط، انقر بالزر الأيمن على التايم-لاين واختر:
     `Timelines` > `Import` > `Timeline Markers from CSV...` (أو `from EDL...`).
   - اختر `markers.csv` أو `markers.edl`.
   - ستظهر العلامات بالألوان التالية:
     - 🟨 **الأصفر (Yellow):** كروت الكابشن التي تتضمن كلمات مشددة (Emphasized/Hot Words).
     - 🌸 **الوردي (Rose):** جملة الهوك الافتتاحية (أول 5 ثوانٍ).
     - 🟩 **النعناعي (Mint):** خاتمة الفيديو والدعوة لاتخاذ إجراء (CTA / Outro).
     - 🟦 **السماوي (Cyan):** بقية جمل الحوار العادية.

## 🎚️ معايير وتوزيع التايم-لاين (Timeline Architecture)

```
[V1] ── [Cut 01] ── [Cut 02] ── [Cut 03] ── [Cut 04] ... (Source: src.mov)
[A1] ── [Audio 1] ── [Audio 2] ── [Audio 3] ── [Audio 4] ... (Denoised Dialogue: a_clean.wav)
[A2] ────── [Whoosh] ────── [Pop] ────── [Hero Hit] ────── [Riser] (SFX from sfx.json)
[ST] ── [Caption 1] ── [Caption 2] ── [Caption 3] ── [Caption 4] (SRT / Subtitles)
```

- **تعديل وقص لقطات الرأس (Talking Head Heads & Tails):**
  نظراً لأن القطع على V1 و A1 عناصر حقيقية وليست فيديو مصمت، يمكنك استخدام أداة التموج (Ripple Edit - B) لتقريب أو إبعاد أي كلمة أو إخفاء أي تنفس زائد بسهولة متناهية.
- **التلوين الاحترافي (Color Grading):**
  في صفحة Color، يمكنك تطبيق LUT المعتمد أو تفعيل Node خاص بالبشرة وتنعيم الوجه وضبط التعريض دون أي تأثير سلبي على النصوص أو الموشن جرافيكس.
- **مكساج الصوت في Fairlight:**
  في صفحة Fairlight:
  - اضبط مسار A1 (الحوار) مع إضافة Voice Isolation و Dialogue Leveler و EQ خفيف لقص الترددات تحت 80Hz.
  - اضبط مسار A2 (المؤثرات) مع موازنة العلو العام لتصل المحصلة النهائية لمعيار الإذاعة والمنصات (`-14.0 LUFS`).

## 🛠️ التكامل مع سكربت ReelForge الرئيسي (`reelforge.py`)

يمكنك استدعاء التصدير تلقائياً بعد اكتمال إنتاج الريل عبر إضافة الخيار `--davinci`:

```bash
python reelforge.py "my_video.mp4" --work "workspace_reel" --davinci
```

وسيقوم ReelForge فور انتهاء عمليات التفريغ والقص والمكساج بتوليد حزمة دافينشي ريزولف كاملة في ثوانٍ معدودة!
