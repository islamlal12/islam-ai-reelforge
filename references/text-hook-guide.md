# 🪝 دليل الهوك البصري النصي للثواني الخمس الأولى (Viral First-5-Seconds Text Hook Engine)

> **المعيار المعتمد من المستخدم:**
> "إلزامية إضافة ميزة Text Hook في أول 5 ثوانٍ من الفيديو (0.0s إلى 5.0s) بخلفية برتقالية (`#F97316`) أو بيضاء (`#FFFFFF`) مطابقة للصور المرجعية الخمس. يتعرف النظام تلقائياً على ما يقوله المتحدث في الثواني الأولى ويصيغ هوك نصي يحمل نفس المعنى بأسلوب فيروسي جذاب مع مؤثر Whoosh/Pop متزامن بالملي، ثم يستأنف الكابشن الحركي الذكي طبيعياً بعد انتهاء الثواني الخمس."

---

## 1. فلسفة الهوك النصي (The 5-Second Hook Philosophy)

أظهرت تحليلات معدل الاحتفاظ في منصات الريلز وتيك توك أن **80% من المشاهدين يقررون التمرير (Scroll Away) خلال أول 3 إلى 5 ثوانٍ**.
عندما يبدأ المتحدث بالكلام فقط دون عنصر بصري صادم، يتطلب استيعاب الرسالة مجهوداً ذهنياً من المشاهد. لذلك يقدم محرّك **Text Hook Engine**:
1. **قراءة فورية بدون صوت:** المشاهد الصامت في بيئة العمل أو المواصلات يقرأ الفكرة في أقل من 1.2 ثانية.
2. **محاذاة دلالية تامة (Semantic Alignment):** لا يخترع كلاماً غريباً؛ يحلل نص أول 5 ثوانٍ من تفريغ وِسبر ويصيغ الفكرة بأقوى صيغة تحفيزية.
3. **تطابق الخامات البصرية:** 5 أنماط مأخوذة حرفياً من أنجح تصاميم الريلز المعاصرة (البطاقة البيضاء، كرت إسلام آي البرتقالي، البادج المزدوج، ستيكر السؤال، وفقاعة الإشعارات).
4. **تزامن سمعي-بصري فوري (Zero-Latency Frame Attack):** دخول الهوك في الفريم 0 مصحوباً بمؤثر `whoosh` ناعم أو `pop` حاد لإجبار انتباه المشاهد.
5. **تسليم سلس للكابشن (Seamless Caption Handoff):** استمرار الهوك النصي طوال أول 5.0 ثوانٍ كاملة، ثم اختفاؤه بنعومة في الثانية 5.0 لتبدأ الكابشنات الحركية السريعة والذكية (`02_captions.py`).

## 2. القواعد الصارمة لمحرك الهوك (Golden Rules)

| الخاصية | المعيار الصارم |
| :--- | :--- |
| **المدة الزمنية (Duration)** | **5.0 ثوانٍ بالضبط** (`0.0s` إلى `5.0s` / فريم `0` إلى `150` بمعدل 30fps). |
| **لوحة الألوان الأساسية** | برتقالي إسلام آي المعتمد (`#F97316`) أو أبيض ناصع (`#FFFFFF`) مع نصوص عالية التباين. |
| **الخط والتايبوجرافي** | `Readex Pro-Bold` (أو `Tajawal-Bold` كبديل احتياطي). |
| **المحاذاة الدلالية** | استخراج المعنى من كلام المتحدث في الثواني الأولى وإعادة صياغته ضمن 5 أطر نفسية فيروسية. |
| **المؤثر الصوتي** | مؤثر صوتي `whoosh_fast` أو `pop_click` في الفريم $F_0$ تماماً (مستوى -12 dBFS). |
| **المنطقة الآمنة** | الارتكاز بين $Y = 520\text{ px}$ و $Y = 760\text{ px}$ (أعلى الصدر، تحت الذقن، أو وسط الكادر بوضع ملء الشاشة). |
| **سلوك الكابشن** | إخفاء الكابشن العادي أو خفضه أثناء الثواني الخمس لتجنب الازدحام، واستئنافه عند $t = 5.0s$. |

## 3. الأنماط البصرية الخمسة المعتمدة (The 5 Visual Styles)

### النمط 1: `card-white` (البطاقة البيضاء البسيطة - Minimalist Clean Card)
*مأخوذ من الصور المرجعية 3 و 5.*
تصميم كرت أبيض مينيمالي فائق النقاء بزوايا ناعمة وظل سينمائي هادئ.

```
       ┌────────────────────────────────────────────────────────┐
       │                                                        │
       │   كيف تبني تطبيق ذكاء اصطناعي كامل في 20 دقيقة؟ ⚡    │
       │                                                        │
       └────────────────────────────────────────────────────────┘
```
- **المواصفات التقنية:**
  - **الخلفية:** `#FFFFFF` (أبيض ناصع) أو زجاجي خفيف `rgba(255, 255, 255, 0.96)`.
  - **الزوايا:** منحنية بنصف قطر `24px` إلى `28px`.
  - **الظل:** `box-shadow: 0 16px 40px rgba(0, 0, 0, 0.22)`.
  - **النص:** لون كحلي/فحمي داكن `#0F172A` بحجم `48px` إلى `54px`.
  - **الكلمات المميزة:** تلوين الكلمة المحورية بلون برتقالي `#F97316` أو أزرق `#0C68E9`.
  - **الأبعاد:** عرض ديناميكي `860px`، حشوة داخلية `padding: 32px 42px`.

  - **الظل:** `box-shadow: 0 18px 48px rgba(249, 115, 22, 0.35)`.
  - **النص:** أبيض ناصع عالي السطوع `#FFFFFF` بحجم `50px` إلى `56px`.
  - **التباين والأثر:** شديد الوضوح على شاشات الجوال ويدفع المشاهد للتوقف الفوري.

### النمط 3: `stacked-badge` (البادج المزدوج المتراكب - Dual Stacked Pill Badge)
*مأخوذ من الصورة المرجعية 2.*
كبسولتان متراكبتان بنصف قطر كبسولي كامل (`border-radius: 50px`). الكبسولة الأولى برتقالية تحذيرية، والكبسولة الثانية سوداء فحمية تحمل جوهر الفكرة مع إيموجي الإنذار 🚨.

```
            ╭─────────────────────────────────────────╮
            │          السر اللي يخفونه عنك           │  ◄── برتقالي #F97316
            ╰─────────────────────────────────────────╯
       ╭───────────────────────────────────────────────────╮
       │   🚨 الأدوات الخمسة اللي غيرت شغلي بالكامل       │  ◄── أسود فحمي #111827
       ╰───────────────────────────────────────────────────╯
```
- **المواصفات التقنية:**
  - **الكبسولة العلوية (Top Pill):**
    - خلفية: `#F97316` (برتقالي الهوية).
    - نص: `#FFFFFF` بحجم `38px - 42px` بخط `Readex Pro-Bold`.
    - زوايا: `border-radius: 9999px` (شكل كبسولة بيضاوية).
    - حشوة: `12px 28px`.
  - **الكبسولة السفلية (Bottom Pill):**
    - خلفية: `#111827` (أسود فحمي داكن).
    - نص: `#FFFFFF` مع إيموجي تنبيه (🚨، ⚠️، 🔥) بحجم `44px - 48px`.
    - زوايا: `border-radius: 9999px`.
    - حشوة: `16px 36px`.
    - تباعد رأسي: `gap: 12px`.

### النمط 4: `question-sticker` (ستيكر سؤال إنستغرام - Instagram Story Question Sticker)

- **المواصفات التقنية:**

  - **الظل:** `box-shadow: 0 20px 50px rgba(0, 0, 0, 0.30)`.

## 4. المحاذاة الدلالية وتوليد الهوكات الذكية (Semantic Alignment Engine)

يقوم المحرك بتحليل نص كلام المتحدث في أول 5 ثوانٍ (`0.0s - 5.0s`) من خلال `a.json` أو ملف التفريغ ويقترح 5 صياغات فيروسية متطابقة مع المعنى الحقيقي:

| الإطار النفسي (Psychological Framework) | الهدف الدلالي | مثال تطبيقي من كلام المتحدث |
| :--- | :--- | :--- |
| **1. فجوة الفضول (Curiosity Gap)** | كشف سر غير مكتمل يجبر المشاهد على الانتظار | *"السبب اللي يخلي نتائجك سيئة بالذكاء الاصطناعي مو الأداة!"* |
| **2. المخالف للسائد (Contrarian / Polarizing)** | كسر معتقد خاطئ شائع لدى الجمهور | *"توقف فوراً عن استخدام ChatGPT بهذه الطريقة الخاطئة!"* |
| **3. التحدي المباشر (Direct Challenge)** | مخاطبة المشاهد وتحديه لتجربة شيء محدد | *"أتحداك تعرف هالميزة الخفية في Claude 3.5 Sonnet!"* |
| **4. الإثبات والأرقام (Social Proof & Numbers)** | تقديم نتيجة ملموسة وواقعية تبني مصداقية | *"كيف اختصرت 8 ساعات شغل يومياً في 15 دقيقة فقط؟"* |
| **5. السؤال الاستفزازي (Provocative Question)** | تحفيز استجابة عاطفية وسؤال مفتوح | *"ليش 90% من المطورين رح يستبدلهم الذكاء الاصطناعي؟"* |

## 5. واجهة الأوامر الطرفية وسير العمل (CLI Commands & Workflow)

يتم تشغيل محرك الهوك عبر السكربت المخصص `scripts/22_hook.py` وفق الأوامر التالية:

### أ) اقتراح الهوكات بناءً على تفريغ الكلام:
```bash
python scripts/22_hook.py suggest <work_dir>
```
- يقوم بقراءة `a.json` أو `a_clean.wav` لأول 5 ثوانٍ.
- يستخرج جوهر المعنى ويطبع 5 خيارات مقترحة موزعة على الأنماط البصرية الخمسة.

### ب) اعتماد وتطبيق الهوك المختار:
```bash
# تطبيق النمط الأبيض مع هوك مخصص:
python scripts/22_hook.py apply <work_dir> --style card-white --text "كيف تبني تطبيق ذكاء اصطناعي في 20 دقيقة؟"

# تطبيق نمط كرت إسلام آي البرتقالي:
python scripts/22_hook.py apply <work_dir> --style card-orange --text "أكبر خطأ تسويه في كتابة البرومبت!"

# تطبيق نمط البادج المزدوج:
python scripts/22_hook.py apply <work_dir> --style stacked-badge --top "سر احترافي" --bottom "🚨 5 أدوات غيرت شغلي بالكامل"

# تطبيق نمط ستيكر السؤال:
python scripts/22_hook.py apply <work_dir> --style question-sticker --text "لو طلبوا منك تختار أداة ذكاء اصطناعي واحدة؟"

# تطبيق نمط فقاعة الإشعار:
python scripts/22_hook.py apply <work_dir> --style chat-bubble --text "لا تنشر أي ريل قبل ما تفحص هذا الشيء!"
```

### ج) معاينة الهوك في فريم ثابت:
```bash
python scripts/22_hook.py preview <work_dir>
```
ينتج هذا الأمر لقطة فوتوغرافية سريعة `<work>/hook_preview.jpg` تعرض الهوك فوق وجه المتحدث بدقة $1080 \times 1920$ للتأكد من تباين النص وخلوه من حجب الملامح.

### د) تصدير طبقة شفافة PNG للهوك:
```bash
python scripts/22_hook.py render_png <work_dir>
```
يصدر ملف `<work>/hook_overlay.png` بدقة $1080 \times 1920$ مع خلفية شفافة Alpha Channel لدمجه الفوري في مسارات التجميع (`04_render_frames.js` أو FCPXML DaVinci Resolve).

1. **الريندر بالكود (`04_render_frames.js`):**
   - في الفريمات من $0$ إلى $150$ ($0.0s \to 5.0s$)، يتم رسم كائن `hook.json`.

   - تنطلق الكابشنات الحركية تلقائياً من $t \ge 5.0s$ بدون أي تداخل بصري.
2. **تصدير دافنشي ريزولف (`42_davinci_export.py`):**
   - يتم تصدير كرت الهوك كطبقة رسومية شفافة (Title / PNG Overlay) على المسار `V2` بطول 5 ثوانٍ كاملة.
   - يوضع المؤثر الصوتي المتزامن `whoosh_fast.wav` على المسار `A2` عند الفريم $F_0$ مباشرة.
