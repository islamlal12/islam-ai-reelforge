> **خطوات تنفيذ البروتوكول الصوتي-البصري:**
> 1. بعد استخراج النص وتصحيحه وحذف التكرار، قسّم الفيديو إلى نبضات سردية (Beats).
> 2. صغ جدول الستوري بورد بدقة تشمل التوقيتات بالثواني، الفريمات الدقيقة، وأسماء المكونات.
> 3. حدد نوع الخامة الصوتية لكل مكوّن (`Glass`، `Tech`، `Paper`، `Solid Metallic`) ومستوى الصوت والطبقات (`Soft`، `Medium`، `Hero 3-Layer`).
> 4. تحقق من مطابقة قاعدة هجوم الفريم (Zero-Latency Attack) وعدم تجاوز ميزانية الأحداث الصوتية (12-14 حدث لكل 10 ثوانٍ).
> 5. اطلب موافقة المستخدم: *"هذا هو مقترح الستوري بورد وتوزيع المشاهد وهندسة الصوت الدقيقة بالفريم، هل تعتمده لنبدأ الريندر؟"*
> 6. لا تبدأ الريندر الكامل إلا بعد استلام الموافقة.

## القواعد الذهبية لمونتاج ريلز عالي الاحتفاظ (Chandler Golden Rules)

### 1. قاعدة ديناميكية الكابشن السريع (High-Retention Fast Captions)
- **دفعة الكلمات (Chunk Size):** ألا يتجاوز الكابشن المعروض في اللحظة الواحدة **2 إلى 3 كلمات فقط** (مثال: "في هذا الفيديو" ← "بنشرح أداة" ← "تغيّر شغلك").
- **تظليل الكلمة المنطوقة:** تظليل الكلمة النشطة حال نطقها فقط بلون التمييز البرتقالي (`#F97316`)، بينما تظهر الكلمات الأخرى في الدفعة باللون الأبيض الصافي (`#FFFFFF`).
- **منع الخلفية الملونة للجمل:** يُمنع تماماً وضع خلفية أو شريط ملون كامل تحت الجملة أو الكلمات، لضمان مظهر سينمائي نظيف وغير مشوش.
- **الخط والهوية:** الخط الدائم هو `Readex Pro-Bold`، ونمط الكابشن `big`.

### 2. نمط التجميد والتفكيك (Pause & Explain / Freeze Frame)
نمط احترافي لشرح تفاصيل الشاشة أو تعليق مهم على نقطة معينة دون تشتيت:
- **المرحلة الأولى (التشغيل):** الفيديو أو تسجيل الشاشة يعمل في نافذة علوية بنسبة **54% من العرض**.
- **المرحلة الثانية (التجميد):** عند نطق كلمة التوقف مع مؤثر نقرة ماوس (`click` أو `tap`)، يتجمد فريم الفيديو فوراً، ويظهر تايم كود مثبت بالزاوية (Timecode HUD: `00:14:22 [PAUSED]`).
- **المرحلة الثالثة (الانكماش والشرح):** بعد 10 فريمات، تنكمش نافذة الفيديو إلى **24% من العرض** بزوايا دائرية خلال 12 فريم بانتقال ناعم (`ease-out cubic`)، لتفسح المجال لظهور بطاقات الشرح، الأكواد، أو عناصر الموشن كيت (`MK.repoCard` أو `MK.promptBar`).
- **المرحلة الرابعة (العودة):** عند انتهاء الشرح، تتمدد النافذة مجدداً إلى **54%** وتستأنف التشغيل الطبيعي بسلاسة.

**مثال تطبيقي في كود المشاهد (`compose.html`):**
```javascript
function pauseExplainScene(t) {
  const tPause = 14.8, tResume = 19.2;
  if (t < tPause || t > tResume) return;
  
  const relT = t - tPause;
  let scale = 0.54;
  let posX = (W - W * scale) / 2;
  
  if (relT > 0.33) { // بعد 10 فريمات تقريباً
    const p = Math.min(1, (relT - 0.33) / 0.4); // 12 فريم انكماش
    const ease = 1 - Math.pow(1 - p, 3);
    scale = 0.54 - (0.54 - 0.24) * ease;
    posX = 60 + (W * 0.1) * (1 - ease); // تنزاح للجانب
  }
  
  // رسم إطار التجميد مع التايم كود المثبت
  drawFrozenFrame(posX, 280, W * scale, H * scale, "00:14:22 [PAUSED]");
}
```

### 3. انتقال السحب السريع (Whip-Pan Transition)
بديل سينمائي راقٍ عن تكرار الزوم الرقمي الرتيب:
- **الخروج (Slide-Out):** في آخر **6 فريمات** (0.2 ثانية) من اللقطة الأولى، تنزاح الصورة أفقياً لليسار بمقدار **8%** مع ضبابية حركة عالية (**Motion Blur 50px**).
- **الدخول (Slide-In):** تبدأ اللقطة التالية مزاحة من اليمين بمقدار **8%** مع بلور **50px**، وتستقر في موضعها المركزي خلال **6 فريمات** بتدرج بطيء ناعم (`ease-out cubic`).
- **المؤثر الصوتي المرافق:** يُرفق دائماً مع انتقال السحب السريع مؤثر صوتي خاطف (`whoosh_fast` أو `swoosh` ذروته تحت `-18 dBFS`).

### 4. وتيرة الـ Jump Cuts وتناوب المقياس (Cadence & Dynamic Scale)
- **إزالة السكتات:** تقطيع أي سكتة أو توقف أطول من **0.22 ثانية** (`silence > 0.22s`) دون تردد.
- **التناوب الحيوي للمقياس (1.0x ↔ 1.15x):** التناوب التلقائي بين مقياسين متقاربين (الكادر الطبيعي 1.0x وزوم مقرب خفيف 1.15x) عند كل قطعية Jump Cut لإعطاء إيقاع حيوي للعين.
- **الأمان الصوتي:** الحذر الصارم من قص بدايات الكلمات (Consonants) أو خنق نهايات الأنفاس؛ يُترك هامش أمان 0.04 ثانية قبل وبعد كل كلمة.

### 5. تخصيص الـ CTA للمنصات (إنستغرام وتيك توك)
عندما يسجل المتحدث خاتمتين للمقطع، يتم إنتاج نسختين مخصصتين بالكامل:
- **نسخة إنستغرام (Instagram Edition):**
  - التركيز على تحفيز التعليقات بالأوتوميشن: *"اكتب كلمة [X] في التعليقات وسأرسل لك الرابط فوراً في الخاص"*.
  - يظهر في المشهد كرت تفاعلي يحاكي صندوق تعليق إنستغرام مع سهم يوجه للأسفل.
- **نسخة تيك توك (TikTok Edition):**
  - التركيز على زيارة البايو أو إنستغرام: *"الرابط موجود في البايو / تابعني في إنستغرام"*.
  - يظهر في المشهد ملصق توجيهي أنيق يشير لأعلى الحساب ورابط البايو.

### 6. الهوية البصرية الصارمة لإسلام آي (Brand & Master Standards)
- **الألوان الرسمية:**
  - الأزرق التقني الأساسي: `#0C68E9` (للكروت والحدود والأزرار الرئيسية).
  - البرتقالي التمييزي الحيوي: `#F97316` (لتظليل الكلمات الساخنة والنبضات المهمة).
  - الأبيض الناصع: `#FFFFFF` (للنصوص الأساسية والعناوين).
- **الخط العربي الدائم:** `Readex Pro-Bold` لجميع النصوص، العناوين، والكابشن.
- **المنطقة الآمنة للمنصات (Safe Zone 1080×1080):**
  - كل العناصر الحيوية (النصوص، الوجوه، الكروت، المؤشرات) تتمركز داخل مربع 1080×1080 بالمنتصف (y: 420 إلى 1500).
  - تجنب الحواف السفلية (y > 1500) لوجود وصف الريل، والجانب الأيمن لوجود أزرار التفاعل (Like, Comment, Share).
- **معايرة الصوت:** `-14.0 LUFS` ثابت لجميع المنصات، والذروة تحت `-1.5 dBTP`.
- **الغلاف في الفريم الأول:** تضمين غلاف الريل المصمم بأول 0.1 ثانية من الفيديو تلقائياً.

## مكونات الموشن التقنية المتخصصة (`motion-kit.js`)

1. `MK.promptBar`: شريط أوامر داكن بنهايات دائرية وكتابة متدرجة بالإنجليزية/العربية مع مؤشر وامض وزر إرسال مميز.
2. `MK.toolLabel`: إبراز شعار أي أداة وانزلاقه لليسار مع خروج اسمها من خلفه لليمين ليستقرا معاً.
3. `MK.repoCard`: بطاقة جيت هاب المظلمة بالمستودع والوصف والنجوم للحلول البرمجية.
4. `MK.wipeSlider`: مسح المقارنة العمودي بسلايدر متحرك من اليمين لليسار.

## شلون تكتب مشهدك

مشاهدك بآخر `compose.html`، بسكربت ثاني تحت سكربت المحرّك:

```html
<script>
SCENES=[{s:0,e:4.1,m:R_FULL},{s:4.1,e:9.8,m:R_DOWN,gb:480},{s:9.8,e:99,m:R_FULL}];
function listPanel(t){
  if(t<4.1||t>9.8) return;
  panelIn(t,4.1,9.8,()=>{ /* رسم بإحداثيات 130..950 × 278..458 */ });
}
SCENE_LIST.push(['listPanel',listPanel]);   // بدون التسجيل ما ينرسم
</script>
```

- `SCENES` تقدر تكتبها بـ`studio.json` بدال الكود.
- كل مشهد ياخذ `t` ويلتصق بتوقيت الكلمة من `caps.json` — لا بتوقيت تقريبي.
  - `wordsOf(i)` = كلمات الجملة رقم i (العدّ من صفر).
- مشهد يشتغل على صورة الفيديو نفسها (مثل القليتش) ينرسم بطبقة الفيديو:
  `SCENE_LIST.push(['myFx',myFx,'video'])`
- من الاستوديو: `studio.json` ← `"sceneFx":["listPanel"]` يسجّل بالاسم.
- مشهد يطيح ينطبع بالطرفية `[compose] ⚠️ مشهد متخطّى` — صلّحه، لا تتجاهله.
- أمثلة للقراءة: `scripts/compose.EXAMPLES.js` (راسه يشرح شلون تحمّله).

## الفكرة — استعارة بصرية، مو زينة

اعصف 3-4 أفكار لكل جملة. الفكرة **تمثّل اللي يقوله**:

| يقول | المشهد |
|---|---|
| يعدّد أشياء | بطاقات تدخل وحدة مع كل كلمة، ثم تنقلب بعلامة صح |
| رقم أو سعر | عدّاد يلف وينزل على الرقم بضربة |
| «انكسر» أو «خطأ» | قليتش يزحزح شرائح الصورة + شقوق |
| مشكلة ثم إصلاح | الكرت يسوَدّ بتحذير ← شريط تقدّم + قائمة تتعلّم بصح |
| «ملف واحد» | كرت ملف، وبطاقات تطير وتندمج فيه |
| دعوة للتعليق | مربع تعليق، والكلمة تنكتب كلمة كلمة |

الجدول أمثلة، مو قالب. **اخترع جديد كل مرة.**

## تفاصيل التخطيط

- `R_DOWN` **كرت مرن:** يصغر حسب أسفل الرسم (`gb`) وعدد أسطر الكابشن.
  فالرسم والكابشن ما يتزاحمان. اللوحات داخل `panelIn()` تتكبّر 1.2 وحدها.
- «ملء الشاشة» يُعرف بالمساحة (`isFull()`) — مو بالزوايا.
- `{s,e,m,nocap:true}` = مشهد بلا كابشن (لما اللوحة فيها النص نفسه).
- شبكة خفيفة بالخلفية كل 60px. توقفها بـ`theme.json` ← `grid:false`.

### اختيار الوضع — قرارك من معنى الكلام

أمر المستخدم (28 سبتمبر): «ما تلتزم بقاعدة… تدرس السكربت وتقرر كرت صغير، اختفي، أو نص في نص».

اقرأ السكربت كامل، ولكل جملة اسأل: **الوجه أهم ولا الرسمة؟**
- انفعال، سؤال، وعد ← الوجه يكبر.
- أرقام وشرح ← الرسمة تاخذ المساحة (`R_LOWER` أو `R_OFF`).
- تعليق على رسمة ← `R_DOWN`.

نصايح مو قيود: الهوك غالباً أقوى بالوجه، والتنويع بين الأوضاع يشد.
الثابت بس: الكابشن ما ينكتب على الوجه، والمنطقة الآمنة.

## البي-رول (اختياري)

فيديو ثانٍ من الشركة؟
1. استخرج المفيد فريمات: `<work>/broll/<اسم>_%04d.jpg`
2. عرّف مداه بـ`BR_NEED`.
3. اعرضه بـ`brCard()` مع `R_LOWER`.
4. `BRCROP` يقصّ الترجمة المحروقة.

3-4 لقطات بالفيديو تكفي.
`R_LOWER` يدخل حزام انستقرام عن قصد — مسموح لأن المغطّى صورة، مو نص.
