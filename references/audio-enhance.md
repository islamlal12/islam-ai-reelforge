### 3.5) «تحسين الصوت الإلزامي قبل وِسبر» — راجع التفاصيل في references/audio-denoise-first.md
في كافة التسجيلات غير المحضرة أو ذات الضوضاء والصدى، **التنظيف الصوتي إلزامي قبل التفريغ لمنع هلوسات وِسبر**:
1. **أدوبي:** لو كونكتور أدوبي موجود بجلسة كلود (أدوات `media_enhance_speech` و`asset_initialize_file_upload`)، **أنت** تناديه: ارفع `<work>/src.mov` لأدوبي (تهيئة الرفع ← رفع القطع بـcurl ← إنهاء الرفع) ثم `media_enhance_speech(assetId)` — يرجّع مسار كلام نظيف ومسار خلفية ومسار صدى. نزّل مسار الكلام وادمجه:
   ```bash
   bash scripts/02b_enhance_audio.sh <work> <clean.wav>
   ```
   المطلوب عند المستخدم: كونكتور أدوبي مفعّل بكلود وحساب أدوبي مسجّل دخوله (النوع `auth`، فحصه بـ`get_account_type`). ما فيه تنزيل على الجهاز.
2. **على الجهاز (الافتراضي والمعتمد محلياً):** `bash scripts/02b_enhance_audio.sh <work> --local [القوة]` أو مباشرة:
   ```bash
   python scripts/02c_denoise.py <work> --pre-whisper
   ```
   - يستخدم **DeepFilterNet 3** (`bin/deep-filter.exe` على ويندوز ولينكس/ماك): تنظيف ذكي يشيل المكيّف والمروحة والشارع والصدى الخفيف دون استهلاك موارد سحابية.
   - القوة 0..1 (الافتراضي 0.85): حد التخفيف داخل الموديل.
   - البديل التلقائي المضمون: لو لم يتوفر DeepFilterNet، ينتقل فوراً وبسلاسة إلى فلتر FFmpeg الطيفي المعياري:
     `afftdn=nf=-25:tn=1,highpass=f=75,lowpass=f=11000,speechnorm=e=4:r=0.0001:l=1,loudnorm=I=-14:TP=-1.5:LRA=7`
3. يُنتج دائماً `work/a_clean.wav` (16kHz mono) لوِسبر، ويُحدث فيديو المصدر `src.mov` بالصوت المعاير لـ -14.0 LUFS (-1.5 dBTP)، ويحفظ الأصل بـ `src_rawaudio.mov`.
