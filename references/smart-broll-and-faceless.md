# الحقن الذكي للقطات الـ B-Roll والإنتاج بدون وجه (Faceless) في DaVinci Resolve

> [!IMPORTANT]
> **القواعد الذهبية الثلاث للميزات الجديدة:**
> 1. **الدمج الذكي لا العشوائي:** لقطات الـ B-Roll الواقعية (Pexels/Pixabay) لا تُلصق عشوائياً لمجرد ملء الفراغ، بل تدمج بوعي إخراجي مع الموشن جرافيكس والرسومات التوضيحية إما كـ **Cutaway ملء الشاشة** (2-4 ثوانٍ) في اللحظات السردية القوية، أو كـ **كرت عائم أنيق (24px Rounded Card)** في وضع `R_LOWER` أو `R_DOWN`، مع مؤثر صوتي يطابق الفريم الأول تماماً.
> 2. **اقتراح أسلوب الدمج المسبق في جدول الستوري بورد:** يُمنع ريندر أي لقطة قبل اقتراح وتوضيح نوع المشهد في جدول الستوري بورد والحصول على موافقة المستخدم: هل النبضة ستكون (متحدث A-Roll، أو ستوك واقعي B-Roll، أو موشن جرافيكس، أو هجين كرت عائم؟).
> 3. **محرك التعليق الصوتي العربي الدقيق (TTS):** **يُمنع تشغيله تلقائياً**، ويُستخدم **فقط وحصرياً إذا طلب المستخدم ذلك صراحة** (مثل: "استخدم التعليق الصوتي"، "ولد صوت بالذكاء الاصطناعي"، "فيديو فيسلس بصوت آلي"). عدا ذلك، تعتمد الأداة دائماً على الصوت البشري الحقيقي وتنقيته بمعيار -14 LUFS.

---

## 1. محرك الـ B-Roll الذكي (`scripts/15_stock_broll.py`)

### مصادر اللقطات:
- **Pexels Video API (مجاني 100%):** يبحث عن لقطات عمودية 9:16 بجودة عالية 1080p/4K.
- **Pixabay Video API (مجاني 100%):** بحث تكميلي سريع ومرخص تجارياً.
- **مجلد محلي (`stock_source/`):** يمكن للمستخدم وضع لقطات خاصة به لتضمينها.
- **مفاتيح الـ API:** تقرأ تلقائياً من متغيرات البيئة `PEXELS_API_KEY` و `PIXABAY_API_KEY` أو من ملف `.env` في المشروع.

### أوامر الاستخدام:
```bash
# 1) البحث واستعراض النتائج:
python scripts/15_stock_broll.py <work> search "ذكاء اصطناعي"

# 2) جلب وقص لقطة محددة وتنسيقها عمودياً 9:16 بمعدل 30fps:
python scripts/15_stock_broll.py <work> fetch --query "cyber security" --dur 3.5 --out broll_01.mp4 --mode cutaway

# 3) تنفيذ خطة ستوري بورد كاملة للبي-رول وحفظ broll_manifest.json:
python scripts/15_stock_broll.py <work> plan --file storyboard_broll.json
```

## 2. جدول الستوري بورد المحدث (Storyboard-First Protocol)

عند تحليل فيديو متحدث (Talking-Head) أو التخطيط لفيديو جديد من الصفر (Faceless)، يُكتب جدول الستوري بورد بالصيغة الشاملة التالية:

| النبضة (Beat) | التوقيت (s) | الفريم (TC) | الكلمات المنطوقة | النوع البصري (Visual Type) | أسلوب العرض (Display Mode) | مصدر المادة (Asset / Query) | المؤثر الصوتي وطبقاته | مستوى الصوت (Layer) |
|---|---|---|---|---|---|---|---|---|
| 1 (الهوك) | 0.0 - 3.2 | F0 - F96 | "لو بتطور نظام ذكاء اصطناعي..." | `A-Roll (متحدث)` | `R_FULL` (زوم سريع) | كاميرا المتحدث الأصلية | `whoosh_fast` + `sub_impact` | `Hero 3-Layer` (-10 dBFS) |
| 2 (البي-رول الواقعي) | 3.2 - 6.8 | F96 - F204 | "في مصانع ومستودعات ضخمة..." | `B-Roll Stock` | `Cutaway (ملء الشاشة)` | Pexels: `automated warehouse robotics` | `whoosh_air` + `mechanical_hum` | `Medium` (-16 dBFS) |
| 3 (الهجين: متحدث + كرت) | 6.8 - 11.2 | F204 - F336 | "هذا التطبيق بيوفر عليك 80%..." | `Hybrid (متحدث + ستوك)` | `R_DOWN` (كرت عائم 24px) | Pexels: `mobile app data scroll` | `card_slide` + `click_tech` | `Medium` (-16 dBFS) |
| 4 (الموشن التوضيحي) | 11.2 - 15.5 | F336 - F465 | "الفرق بين السيرفر القديم والجديد" | `Motion Graphic` | `R_LOWER` (سلايدر مقارنة) | `MK.wipeSlider` (رسومات كودية) | `servo_wipe` + `crystal_ping` | `Medium` (-14 dBFS) |
| 5 (الخاتمة والـ CTA) | 15.5 - 20.0 | F465 - F600 | "اكتب 'كود' في التعليقات لأرسل لك..."| `A-Roll + كرت تفاعلي` | `R_DOWN` (زر إنستغرام) | كرت الهوية + حساب إسلام آي | `riser_0.5s` + `hero_boom` | `Hero 3-Layer` (-10 dBFS) |

### أساليب الدمج الأربعة في المونتاج:
1. **Cutaway كامل (Fullscreen B-Roll):** قطع كامل من المتحدث إلى لقطة الستوك لمدة 2.5 - 4 ثوانٍ مع زوم بطيء ناعم (Slow Push-in) والكابشن يرتكز في المنطقة الآمنة Y=1320-1420.
2. **الكرت العائم (Floating Rounded Card):** المتحدث يبقى ظاهراً في الثلث السفلي، ولقطة البي-رول تظهر في كرت زواياه 24px بإطار خفيف بلون الثيم (`#0C68E9`) مع ظل ناعم، مما يعطي إحساساً فخماً بالعمق البصري.
3. **تجميد وشرح (Pause & Explain):** تجميد لقطة الفيديو/الشاشة، تصغيرها لـ 24%، وظهور لقطة الستوك أو الموشن بجانبها للشرح.
4. **الموشن التوضيحي البحت:** عندما تكون المعلومة رقمية (إحصائيات، كود، مقارنات)، الأولوية لمكتبة `motion-kit.js` وليس للفيديو الستوك.

## 3. تايم لاين DaVinci Resolve المفتوح للـ Faceless (`42_davinci_export.py`)

عند العمل في وضع الفيسلس (Faceless) بدون كاميرا بشرية، أو عند طلب تصدير التايملاين:
```bash
python scripts/42_davinci_export.py <work> --faceless [--import]
```

### بنية التايم لاين المفتوح داخل DaVinci Resolve:
- **مسار الفيديو V1 (Primary Storyline):** تتوزع عليه لقطات الـ B-Roll المستقلة (`broll_01.mp4`, `broll_02.mp4`...) مقصوصة ومحاذاة بدقة متناهية مع كل نبضة سردية. يستطيع المونتير تبديل أي كليب أو تلوينه بشكل منفصل تماماً بضغطة زر.
- **مسار الصوت A1 (Master Dialogue):** مسار التعليق الصوتي الصافي والمعاير بدقة البث (-14.0 LUFS).
- **مسار الصوت A2 (SFX Design):** ضربات ومؤثرات الانتقال (Whooshes, Hits, Risers) موزعة عند فريم بداية كل لقطة B-Roll ($F_0$).
- **مسار الترجمة (Subtitle Track):** ملف `timeline.srt` و الماركرز الملونة التي تحمل نصوص الحوار والكلمات المفتاحية المشددة.
- **الاستيراد الآلي:** تشغيل `python import_to_davinci.py` ينشئ المشروع في DaVinci Resolve Studio فوراً ويضبط دقة المشروع على 1080×1920 عمودي 9:16.

## 4. محرك التعليق الصوتي العربي الدقيق (`scripts/01c_tts_engine.py`)

> [!CAUTION]
> **شرط التفعيل الصارم:** يُستخدم هذا المحرك **فقط إذا طلبه المستخدم صراحة**. لا يتم توليد صوت اصطناعي إذا كان المستخدم قد زوّد تسجيلاً صوتياً أو فيديو كاميرا.

### المميزات:
- يعتمد خامات صوتية عربية فصحى فائقة النقاء عبر Edge Neural Voices:
  - `ar-SA-HamedNeural` (افتراضي ذكوري: وقور، هادئ، مخارج حروف عربية فصيحة ومثالية للشروحات).
  - `ar-EG-SalmaNeural` (افتراضي أنثوي: واثق ومحفز).
  - `ar-AE-HamdanNeural` (لهجة خليجية حديثة).
- يستخرج توقيت الكلمات بالمللي ثانية ويولد تلقائياً `a.json` مطابقاً بنسبة 100% لمخرجات وِسبر.
- يولد `audio.wav` و `a_clean.wav` بجودة 48kHz Stereo وموزونة عند -14.0 LUFS.

### طريقة التشغيل:
```bash
# نص مباشر:
python scripts/01c_tts_engine.py <work> --text "النص الكامل هنا..." --voice ar-SA-HamedNeural --rate +5%

# من ملف سكربت:
python scripts/01c_tts_engine.py <work> --file script.txt
```
ثم يكتمل المونتاج مباشرة عبر الخطوات المعتادة: `02_captions.py` ثم `42_davinci_export.py`.
